# siteptp

Site officiel de téléchargement de **PaperTaPeur**.

Le site présente les versions :
- Windows (.exe)
- Android (.apk)
- Linux (.AppImage)
- macOS (.dmg)
- iPhone/iPad via PWA
- Navigateur

Les boutons natifs se connectent automatiquement à la dernière **GitHub Release** du dépôt `GabyY-1/PaperTaPeur`. Dès qu'un fichier .exe, .apk, .AppImage ou .dmg est ajouté à une release, le bouton correspondant devient automatiquement disponible.

Le jeu web est disponible sur : https://gabyy-1.github.io/PaperTaPeur/
